# AI Eraser

A Chrome extension prototype that conservatively flags posts containing explicit AI disclosures. It does not verify authorship; it only surfaces likely disclosures and lets you override the decision.

## What it does

- Flags posts that explicitly mention AI-generated, generated by AI, or made using AI wording.
- Shows a visible reason panel above the post, so you know why it was flagged.
- Lets the user choose the safer path:
  - Show anyway (not AI)
  - Confirm AI
- Stores those corrections in browser storage for local review.
- Lets you toggle automatic hiding on or off from the extension popup.

## Install in Chrome

1. Open `chrome://extensions`.
2. Turn on Developer mode.
3. Choose Load unpacked.
4. Select the folder containing `manifest.json`.
5. Visit a supported feed and test the behavior.

## Supported sites

- X / Twitter
- Facebook
- Instagram
- LinkedIn
- Reddit
- YouTube

## Conservative behavior

This extension is intentionally not aggressive. It only looks for explicit AI disclosure wording and ignores generic writing patterns, image URLs, and other weak signals. That keeps false positives much lower, but it will also miss content that is AI-generated without saying so.

## Feedback and tuning

The popup exposes a small local feedback panel that records false positives, confirmed AI hits, and rule-level counts by match type. These counts are stored locally in the browser and can be exported or cleared from the popup. Feedback does not upload or automatically retrain/change detection rules.

## Files

- `manifest.json` — extension metadata and popup wiring
- `content-script.js` — post detection, reason panel, controls, and local feedback
- `popup.html` — popup UI
- `popup.js` — settings and feedback logic
- `popup.css` — popup styling

## Limitation

This is not a reliable AI detector. It is a conservative disclosure-based helper that reduces noisy blocking and gives users final control.

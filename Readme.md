# AI Eraser

A Chrome extension prototype that conservatively flags posts containing explicit AI disclosures. It cannot verify whether content was generated by AI: text and image metadata are incomplete and can be misleading.

## Install in Chrome

1. Open `chrome://extensions` and enable **Developer mode**.
2. Select **Load unpacked** and choose the folder containing `manifest.json`.
3. Visit a supported feed (X/Twitter, Facebook, Instagram, LinkedIn, Reddit, or YouTube).

## Conservative behavior

- Automatic hiding is enabled by default, but only narrow, explicit disclosure wording triggers it. Generic writing-style phrases and image URL metadata are intentionally ignored.
- Each hidden post has a notice explaining the matched signal. Choose **Show anyway (not AI)** to reveal it and record a false positive, or **Confirm AI** to record a true positive.
- Use the extension popup to turn automatic hiding off. In that mode, matching posts are flagged but remain visible.
- Feedback is aggregated by rule and stored in `chrome.storage.local` on this device. The popup shows the counts and can export or clear them. It does not upload data or automatically retrain/change rules; use the measured false-positive and confirmation counts to review rules before changing them.

## Limitations

This is not a dependable AI detector. Posts without explicit disclosure will usually not be caught, and disclosures can be jokes, quotations, or inaccurate. Site layouts change, so selectors may need maintenance. Review any flag before relying on it.
